# SPEC_export_workbook_e — 수식 이름 치환·차가감 식 정리 · 작성 Claude 2026-10-25
브랜치 `feat/export-workbook`(이어서). 정답 테스트 `tests/test_export_workbook_e.py` + 기존 전부 통과. 커밋 1개(제목: fix: 수식 숫자 토큰과 차가감 계산식 정리). push 금지, 테스트 수정 금지.

1. `_이름_치환` 숫자 토큰: 숫자는 `숫자[.숫자][e|E[+|-]숫자]`까지만 읽는다. `+`·`-`는 바로 앞이 `e`/`E`이고 바로 뒤가 숫자일 때만 숫자의 일부, 그 밖에는 연산자 토큰. `e`/`E` 뒤에 숫자(또는 부호+숫자)가 없으면 숫자를 거기서 끝내고 `e`/`E`부터는 이름으로 읽는다.
   - `2-EBIT` → `2-호출1_EBIT`, `12-항목1` → `12-호출1_항목1`, `0.1*항목2` → `0.1*호출1_항목2`, `1.5E+2-항목1` → `1.5E+2-호출1_항목1`, `3E항목1`처럼 지수 없는 E는 `3*`가 아니라 그대로 `3` + 이름 `E항목1`(맵에 없으면 그대로).
2. `income_adjustment_total`의 `각사업연도소득금액` 식: 기부금한도초과·이월공제가 0인 항은 식에서 뺀다. 둘 다 0이면 식은 `차가감소득금액`, 한도초과만 있으면 `차가감소득금액+기부금한도초과`, 둘 다 있으면 `차가감소득금액+기부금한도초과-기부금이월공제`, 이월공제만 있으면 `차가감소득금액-기부금이월공제`. `+0`·`-0` 금지.
3. 같은 줄의 f-string 안 따옴표 중첩을 없앤다(Python 3.10·3.11에서 SyntaxError). 식은 f-string 밖에서 조립. `requires-python >=3.10`이므로 server.py 전체가 3.10 문법으로 파싱돼야 한다.
4. 세무조정 항목 입력 이름은 가산·차감 통틀어 `항목1`부터 빠짐없이 이어서(가산 N개 → 차감은 `항목N+1`부터). 지금은 차감이 `len(계산식_입력)` 기준이라 당기순이익·기부금 입력 수만큼 번호가 건너뜀.
