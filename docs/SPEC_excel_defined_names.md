# SPEC: export_workbook 정의 이름을 엑셀 규칙에 맞추기 (0.12.2)

작성 Claude 2026-10-26. 테스트: tests/test_excel_defined_names.py (수정 금지).

## 문제
export_workbook이 만드는 정의 이름(defined name)에 띄어쓰기·괄호 등이 들어간다.
예: `호출1_시부인 대상`, `호출2_기초 미상각잔액(즉시상각의제 포함)`, `호출8_배당(Gross-up 대상)`.
Microsoft Excel은 이런 이름을 읽지 못해 파일을 열 때 "내용에 문제가 있습니다 → 복구" 창을 띄운다
(LibreOffice는 그냥 열어서 지금까지 몰랐음). 실제 사용자는 Excel로 연다.

## 고칠 것
1. 정의 이름을 만드는 모든 곳(forms·steps 두 layout, 입력·계산식·결과 이름 전부)을 하나의 헬퍼로 거친다.
   - 허용 문자: 한글(가-힣), 영문, 숫자, 밑줄 `_`, 마침표 `.` 만. 그 밖의 문자(공백·괄호·하이픈·%··/·, 등)는 `_`로 바꾸고, 연속 `_`는 하나로, 끝의 `_`는 지운다.
   - 첫 글자는 한글·영문·밑줄. 아니면 앞에 `_`를 붙인다.
   - 셀 주소처럼 읽히는 이름(예 `A1`, `AB12`, `R1C1`, `R`, `C`)이 되면 앞에 `_`를 붙인다.
   - 255자 이하.
   - 같은 통합문서 안에서 대소문자 무시하고 겹치면 뒤에 `_2`, `_3`…을 붙여 유일하게.
2. 수식 안에서 이름을 참조하는 곳(_이름_치환에 넘기는 이름 맵 등)도 바뀐 이름을 그대로 써야 한다. 수식이 가리키는 이름은 모두 실제로 정의돼 있어야 한다.
3. 시트에 보이는 글자(단계명·설명 열 등)는 바꾸지 않는다. 바뀌는 건 정의 이름뿐.
4. 계산 값·확인 열("일치")·서식 모양은 그대로.

## 통과 기준
- tests/test_excel_defined_names.py + 기존 테스트 전부 통과.

## 추가(2차 리뷰)
- 저장한 xlsx를 다시 열어 XML을 고쳐 쓰는 후처리(&#NNN; 복원 ZIP 재작성)는 넣지 않는다. 엔티티는 유효한 XML이고, 테스트는 html.unescape로 읽도록 고쳤다. export_workbook에서 그 후처리 블록과 쓰지 않게 된 import(io, zipfile)를 지운다.
