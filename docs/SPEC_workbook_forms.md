# SPEC_workbook_forms — 엑셀을 법정서식 순서·모양으로 · 작성 Claude 2026-10-25
새 브랜치 `feat/workbook-forms`(main 기준). 정답 테스트 `tests/test_workbook_forms.py` + 기존 전부 통과(기존 export_workbook 테스트 중 이 명세와 충돌하는 것은 Claude가 정리함 — 아래 "기존 테스트"). 커밋 1~3개. push 금지, 테스트 수정 금지.

## 왜
실무자는 세무조정계산서를 법정서식(법인세법 시행규칙 별지 서식) 순서·행 번호로 본다. 지금 엑셀의 `요약`(키·값 나열)과 `계산 N`(계산식 단계 나열)은 낯설다. 서식 원문은 국가법령정보센터 현행 서식 PDF로 확인(아래 행 이름은 그 원문 그대로).

## 1. export_workbook 인자 추가(선택)
- `layout`: `"forms"`(기본, 이 명세) 또는 `"steps"`(지금 모양 그대로: 요약 + 계산 N). 기존 export_workbook 테스트는 Claude가 `"layout": "steps"`를 붙여 둠.
- `company`(법인명, 기본 ""), `period`(사업연도 표기, 예 `"2025.01.01 ~ 2025.12.31"`, 기본 ""). 서식 시트 머리에 적는다.

## 2. 시트 순서 (해당 call이 있을 때만 그 시트를 만든다)

| 2 | `별지3 과세표준및세액조정계산서` | income_adjustment_total |
| 3 | `별지15 소득금액조정합계표` | income_adjustment_total(세무조정) |

| 4-2 | `별지23(을) 기업업무추진비` | entertainment_adjustment |
| 5 | `별지20(1) 감가상각비(정률법)` / `별지20(2) 감가상각비(정액법)` | depreciation_adjustment(방법에 따라) |
| 6 | `별지16의2 수입배당금액명세서` | dividend_received_deduction |

- **자료 원칙**: 사례(도구 입력)에 숫자가 있는 서식만 시트로 만든다. 자료가 없거나 해당 없는 관련 서식은 `목록`에 `서식 이름 — 자료 없음(이유)` 또는 `해당 없음`으로만 적는다. 예: `별지50(갑) 자본금과 적립금조정명세서 — 재무상태표 자본 자료 없음`, `별지50(병) — 해외현지기업 출자 해당 없음`.
- 위 표에 없는 도구는 지금의 `계산 N` 시트 방식 그대로(대체 경로). 같은 도구 call이 둘 이상이면 같은 서식 시트에 열(자산·법인)을 더하거나 시트 이름 뒤에 ` (2)`.

## 3. 서식 시트 공통 모양
- 1행: 서식 표기(예 `법인세법 시행규칙 [별지 제23호서식(갑)]`), 2행: 서식 이름, 3행: `사업연도 | {period} | 법인명 | {company}`.
- 행 표: **A 번호 | B 구분(서식 원문 항목명) | C 금액 | D 산식(서식 원문 괄호식, 텍스트) | E 도구 값 | F 확인**. 금액(C)은 수식 — 같은 시트 다른 행 셀 참조 또는 `입력·가정`의 이름(`호출N_…`) 참조. 서식이 산식을 주는 행(예 ⑧ = ④+⑥+⑦)은 그 산식 그대로 셀 참조. E는 도구가 낸 값, F는 `=IF(ROUND(C,0)=ROUND(E,0),"일치","확인 필요")`(도구 값이 없는 행은 E·F 비움).
- 비율 행(상각률, 익금불산입 비율 등)은 C에 비율 값.
- 서식 사이 연결은 실제처럼: 별지23 ⑯·별지20 ㉖(정액법 ㉓)·별지16의2 ⑰ → 별지15 해당 줄 금액이 그 셀 참조(도구 세무조정과 금액이 같을 때), 별지15 ②·⑤ 합계 → 별지3 102·103.
