# SPEC_form_templates3 — 법정서식 3단계(부가·종소) · 작성 Claude 2026-10-25
브랜치 `feat/workbook-forms`(이어서). 정답 테스트 `tests/test_form_templates3.py` + 전체. 커밋 1~2개. push 금지, 테스트·틀 JSON 수정 금지. 틀 5개(부가22·부가근거63·부가근거64·종소배당·종소근로)는 Claude가 넣어 둠 — 부가 계산근거 2개는 법정서식이 없어 "서식 없음"을 머리에 적은 Claude 양식.

## 1. 순서
2단계 순서 뒤에 `부가22, 부가근거63, 부가근거64, 종소배당, 종소근로`.

## 2. 새 source
- `공통사용재화`(common_input_tax): args `common_asset_sales` 순서대로 `{순번: 1..}`(열 수식이 `[입력.공급가액{i}]`로 값 참조).
- `배당명세`·`이자명세`(financial_income_aggregate): 도구 보강 — 결과 `계산`에 `항목별`: [{항목(kind), 금액, 구분}] 추가. 구분은 도구 내부 분류 그대로: `GU대상`(Gross-up 대상 배당), `GU비대상`(그 밖 배당), `출자공동`, `이자`, `제외`(분리과세·과세 제외). source 행: 배당명세 = GU대상·GU비대상·출자공동, 이자명세 = 이자. `제외`는 넣지 않음. 각 행 `{코드, 일련번호, 항목, 금액}`: 코드는 배당 GU대상 21·GU비대상 22·출자공동 28, 이자 13(종합소득세 신고서 ❺❻ 작성방법). 코드 오름차순, 같은 코드 안에서는 입력 순서, 일련번호는 코드별 1부터. 항목은 kind의 `_`를 공백으로.
## 3. 문구·조건
- `{{과세기간}}`(부가22): common_input_tax args `year`·`period`로 `"{year}년 제1기 ( 1월 1일 ~ 6월 30일 )"` / 제2기 `( 7월 1일 ~ 12월 31일 )`.
- `{{label}}`: 그 call의 label.
- 틀 `when`에 `[결과.키]`도 쓸 수 있음(종소배당: `[결과.분리과세]==FALSE`). bool은 TRUE/FALSE로 비교.
- 종소배당이 when 때문에 빠지면 `목록`에 `❻ 배당소득명세서·❺ 이자소득명세서 — 해당 없음(금융소득 2천만원 이하 분리과세)`.
