## 검수에서 나온 것 (무작위 입력 각 도구 40~60건을 식으로 직접 계산해 도구 값과 대조)
1. **financial_income_aggregate 식이 도구와 다름(10/40건)**
   - 합계가 정확히 2천만 원이면 도구는 분리과세(초과일 때만 종합과세, 소득세법 제14조③6호)인데 식은 `threshold>합계`라 종합과세로 계산.
   - 2천만 원 판정 합계에 출자공동사업자배당을 넣음. 도구처럼 **판정 합계에서 제외**해야 함.
   - 식은 도구 코드와 같은 순서로: `판정합계 = 이자 + 비대상배당 + 대상배당 − 출자공동사업자배당`, `종합과세여부 = 판정합계 > 기준금액`, 그다음 이자 → 비대상 → 대상 순으로 기준금액을 채움.
2. **financial_income_aggregate 도구 값 버그**: 분리과세인데 출자공동사업자배당이 있으면 `합산액`은 그 금액(예: 24,000,000)인데 `배당소득금액`이 0. 출자공동사업자배당도 배당소득이므로 분리과세일 때 `배당소득금액` = 출자공동사업자배당, `이자소득금액` = 0. 종합과세일 때는 지금 그대로.
3. **common_input_tax 추가 매출세액 1원 차이(25/60건)**: 공통사용재화가 여러 개면 도구와 식의 절사 위치가 다름. 식이 도구와 같은 위치에서 절사하도록(도구 값은 그대로 둠). 기존 테스트가 고정한 값은 바꾸지 않는다.
4. **판단이 아닌 산술은 식으로**: 아래는 지금 도구가 미리 계산해 입력으로 넣고 있음 → 원래 입력을 두고 식 단계로.
   - 감가상각: `정률법_기초미상각잔액` = `취득가액 − 기초감가상각누계 + 전기부인누계 + 즉시상각의제`, 정액법 취득가액도 `취득가액 + 즉시상각의제…`. `회사계상액` = `장부상각비 + 즉시상각의제`.
   - 수입배당: `대상배당금N` = `수입배당금액N − 제외배당금N`, `차입금이자` = `MAX(0, 지급이자 − 제외이자)`.
   - 공통사용재화: `직전과세비율` = `직전과세공급가액 / (직전과세공급가액 + 직전면세공급가액)`(직전 면세 공급이 없거나 안분 제외 사유면 판단 결과 입력으로 두고 설명에 사유).
   - 일괄양도: 부가세 포함 시 건물 = `총거래가액 × 기준건물 / (기준건물 × 1.1 + 기준토지)` 꼴로(지금 `L_B비` 식은 맞지만 읽기 어려움).
5. **이름은 한글로**: 실무자가 엑셀에서 보는 이름. `total_price`·`vat_included`·`threshold`·`rate`·`*_input`·`partner_div_input`·`is_정액법`·`L_B비` 등 영문·혼용 이름을 한글로(예: `총거래가액`, `부가세포함여부`, `종합과세기준금액`, `가산율`, `출자공동사업자배당`, `정액법여부`). 예외는 `GrossUp`(결과 키 `Gross-up`) 하나. 기업업무추진비의 `수입금액일반한도티`·`수입금액합계한도티` → `수입금액일반한도`·`수입금액합계한도`.
6. **입력은 숫자 또는 TRUE/FALSE만**: 감가상각의 `method`(문자열 "정률법") 입력 제거(`정액법여부` 하나로).
7. **값만 붙인 식 금지(수입배당)**: 차입금이자가 0이면 `차감액N`의 식이 `0`이 됨 → 0이어도 같은 식(`차입금이자 × …`)을 쓴다. 모든 단계 식은 이름을 하나 이상 참조(SPEC c 규칙).

## 정답 테스트
- 이름 규칙: 모든 `계산식_입력`·`계산식` 이름이 `^[가-힣][가-힣0-9_]*$`(예외 `GrossUp`), 입력 값은 int/float/bool.
- 고정 시드 무작위 입력(도구별 40건): 모든 단계 식 = 값, 결과 키와 같은 단계 값 = 결과.
- 금융소득 경계값: 정확히 2천만(분리), 2천만+1(종합), 출자공동사업자배당만 2,400만(분리, 배당소득금액·합산액 2,400만), 상장 1,300만 + 출자공동 2,000만(분리, 합산 2,000만).
- 산술 입력 제거 확인: 감가상각 입력에 `정률법_기초미상각잔액`이 없고 같은 이름의 단계가 있음, 수입배당 `대상배당금1`·`차입금이자`가 단계.
