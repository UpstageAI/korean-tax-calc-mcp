## 충돌
`entertainment_adjustment` 두 곳. 이 브랜치는 2025.1.1 이후 전통시장 추가한도(`market=`, 산식 문장)를 넣었고, main은 같은 함수에 엑셀 계산식(`계산식_입력`·`계산식`)을 넣었다.

## 해결 규칙
- 두 쪽 모두 살린다: `C.entertain(..., market=전통시장_총액 if year >= 2025 else 0, months=months)` + 이 브랜치의 산식 문장 + main의 `계산식_입력=…, 계산식=…`.
- 계산식에 전통시장 한도를 넣는다(2025 이후, 전통시장 지출이 있을 때): 입력 `전통시장금액`(설명에 항목·조문 조특법 제136조), 단계 `전통시장한도` = `MIN(전통시장금액, 일반한도 × 10%)` 꼴(일반한도는 지금 계산식의 기본+수입금액 일반분 단계 이름 사용), `한도` 식에 `+전통시장한도`. 2024 이전이거나 지출이 없으면 단계를 넣지 않음.
- 도구 값은 이 브랜치 그대로(전통시장한도 7,840,000, 한도초과 17,760,000).
