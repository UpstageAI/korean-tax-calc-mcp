# SPEC_form_templates — 엑셀을 법정서식 그대로(서식 틀 + 값 채우기) 1단계 · 작성 Claude 2026-10-25
브랜치 `feat/workbook-forms`. 정답 테스트 `tests/test_form_templates.py` + 기존 전부 통과. 커밋 1~2개. push 금지, 테스트 수정 금지. 서식 원문 행 규칙은 docs/SPEC_workbook_forms.md 4절 참고.

## 왜
실무자는 법정서식 모양(병합 칸·괘선·행 번호·A4 한 장) 그대로 보기를 원함(승미님이 Claude 시안 `별지23갑 서식그대로 시안.xlsx`를 보고 "바로 저거" 확정). 서식 모양은 **데이터(JSON 틀)**로, 코드는 **틀을 그리고 금액 자리에 수식을 채우는 렌더러**로 나눈다. 틀은 Claude가 서식 PDF(국가법령정보센터 현행본)를 보고 작성 — 이번 단계는 `korean_tax_calc_mcp/data/form_templates/별지23갑.json`·`별지23을.json`(이미 있음, 수정 금지).

## 1. export_workbook 인자 추가
- `layout`: `"forms"`(기본) | `"steps"`(지금 모양 그대로: 요약 + 계산 N + 입력·가정 + 판단·근거). 기존 테스트는 `steps`.
- `company`(법인명, 기본 ""), `period`(`"YYYY.MM.DD ~ YYYY.MM.DD"`, 기본 ""), `biz_no`(사업자등록번호, 기본 "").

## 2. forms 시트 구성
1. `목록`: 만든 서식 시트 이름·서식 표기(틀의 `form`)를 순서대로 + 자료 원칙에 따른 줄: 법인세 도구 call이 하나라도 있으면 `별지 제50호서식(갑) 자본금과 적립금조정명세서 — 자료 없음(재무상태표 자본 자료 필요)`, `별지 제50호서식(병) — 해당 없음(해외현지기업 출자)`. 맨 아래 고지 문구(지금 요약 시트의 것).
2. 틀이 있는 도구의 call은 틀 시트로(이번 단계: entertainment_adjustment → 별지23(갑) 다음 별지23(을)). 같은 도구 call이 둘 이상이면 시트 이름 뒤 ` (2)`.
3. 틀이 없는 도구 call은 지금의 `계산 N` 시트(steps와 같은 방식) — 틀 시트 뒤, call 순서대로.
4. 끝: `입력·가정`(통합 문서 이름 `호출N_이름` 유지), `판단·근거`. `요약` 시트는 forms에서 만들지 않음.

## 3. 틀 JSON 형식
- `key`(교차 참조용 이름), `sheet`(시트 이름), `form`, `tool`, `widths`{열: 너비}, `row_heights`{행: 높이}, `default_row_height`, `cells`[{`r` 셀 또는 병합 범위, `t` 문구, `al` l|c|r, `size`?, `bold`?}], `box`[괘선(얇은 선) 범위], `outer`[바깥 굵은 선 범위], `amount_cols`[금액 열 — 숫자 서식 `#,##0`, 오른쪽 정렬], `print_area`, `check_col`, `slots`[{`id`, `cell`, `merge`?, `f` 수식 문자열, `check`? 도구 값 경로}].
- 문구 자리표시: `{{법인명}}`·`{{사업자등록번호}}`·`{{기간_시작}}`·`{{기간_끝}}`(period를 ` ~ `로 나눔)·`{{입력.이름}}`(그 call 계산식_입력 값, 정수면 그대로)·`{{계정과목}}`(기본 `기업업무추진비`).
- 수식 토큰(`f`):
  - `{id}` → 같은 시트 그 slot 셀 주소(예 `D8`).
  - `{틀key!id}` → 다른 틀 시트 셀(`'별지23(을) 기업업무추진비'!F13`). 같은 call에서 만든 시트를 가리킴. 없으면 오류.
  - `[입력.이름]` → 그 call의 통합 문서 이름 `호출N_이름`(입력·가정 셀). `[결과.경로]`·`[계산.경로]` → 도구 결과 값(숫자) 그대로. `[…|기본값]`: 없으면 기본값. 기본값 없이 없으면 오류(조용히 0 금지).
  - 숫자·연산자·함수(MIN·MAX·IF·SUM·ROUND·ROUNDDOWN·ABS)·셀 주소는 그대로.
- 렌더: 글꼴 맑은 고딕(크기 기본 10), 눈금선 끔, 줄바꿈 켬, 세로 가운데. `box` 범위 모든 칸 얇은 선, `outer` 바깥 테두리 굵은 선. A4 세로, 한 쪽 맞춤, `print_area` 지정.
- 검증 칸: slot에 `check`가 있으면 `check_col`에 도구 값(회색 9pt), 바로 오른쪽 칸에 `=IF(ROUND(금액칸,0)=ROUND(도구값칸,0),"일치","확인 필요")`. 첫 검증 행 위 머리에 `도구 값`·`확인`. 인쇄 영역 밖.
- 무한대(inf) 값은 셀에 쓰지 않는다(입력·가정에는 빈 칸 + 설명 `상한 없음`).

## 4. 도구 보강 (entertainment_adjustment)
- `계산`에 `전통시장_지출`·`지역사랑상품권_지출`·`온누리상품권_지출` 추가: 그 사업연도에 추가한도 **대상인** 성격의 지출 합계(SPEC_gold_gaps5e 표 — 대상 아니면 0, 일반 기업업무추진비로 시부인).
