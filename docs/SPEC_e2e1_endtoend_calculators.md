# SPEC e2e1 — 끝에서 끝까지 계산기 시범 3종 (2026-10-13)

## 배경 (세무사 기출 20회차 실측)
- 계산 23문항 × 3회: 계산기 호출 10/69, 계산기 사용 시 정답 0. 계산기 자체는 정확(2024-65·66 손계산 일치)하나 **항목 판단·세법상 금액 조정·중간 계산이 전부 모델 몫**이라 못 씀
- 원칙(미아): 계산기는 ① 항목 판단(인정·부인과 근거 조문) ② 세법상 금액 조정 ③ 중간 계산 ④ 최종 계산·세무조정까지. 입력은 정리된 숫자가 아니라 **원래 사실관계**

## 공통
- 새 도구 3개(기존 도구는 그대로 두고 추가). 결과에 `판단`(항목별: 항목, 결론, 금액, 근거 조문, 이유 한 줄), `계산`(중간값), `결과`, `세무조정`(있으면: 구분·금액·소득처분) 키
- 도구 설명은 "언제/입력/결과" 형식. 각 입력 필드에 한국어 설명
- 연도별 규정 차이는 year로(최소 2023~2026)

## 1. bad_debt_adjustment — 대손금·대손충당금 세무조정
입력
- year, sme(bool), prior_excess(전기 대손충당금 한도초과액)
- book: {opening, offset, provision, closing} (장부상 대손충당금 기초·당기상계·당기설정·기말)
- receivables_prev_end_book, receivables_end_book (장부상 설정대상 채권 전기말·당기말)
- writeoffs: [{kind, amount, arose_in: '전기'|'당기', instrument?: '외상매출금'|'받을어음'|'기타', months_since_default?, mortgage?: bool}]
  - kind: '소멸시효완성'(상법·민법 등) | '화해·확정판결' | '부도6개월' | '회수불능'(파산·강제집행 등)
- loss_rate_digits(대손실적률 소수 자릿수, 기본 3 — 넷째 자리 이하 절사)
규칙(근거 법인세법 제19조의2·제34조, 시행령 제19조의2·제61조)
- 소멸시효완성·화해 등: 신고조정 대손 — 사유 발생 사업연도의 손금. arose_in='전기'인데 당기 장부 처리 → 당기 손금불산입(유보 추인), 전기말 세법상 채권에서 차감
- 부도6개월: 결산조정. 받을어음은 인정, 외상매출금은 중소기업만 인정(부도 이전 발생분), 저당권 설정 시 불인정. 인정분은 채권별 1,000원 비망가액 공제
- 세법상 당기 대손금 = 인정 대손금 합계 / 세법상 전기말 채권 = 장부 전기말 − 전기 사유 신고조정 대손 / 세법상 당기말 채권 = 장부 당기말 + 부인 채권(비망 포함)
- 대손실적률 = 세법상 당기 대손금 ÷ 세법상 전기말 채권(절사), 한도 = 세법상 당기말 채권 × max(1%, 실적률), 한도초과 = 장부 기말잔액 − 한도
- 세무조정: 부인 대손(손금불산입·유보), 전기 사유분(손금불산입·유보), 한도초과(손금불산입·유보), 전기 한도초과(손금산입·△유보)

## 2. entertainment_adjustment — 기업업무추진비 세무조정
입력: year, sme, months, revenue_general, revenue_related, expenses: [{amount, evidence: '없음'|'영수증 등'|'적격', over_30k?: bool(기본 true), congratulatory?: bool, culture?: bool}]
규칙(법인세법 제25조, 시행령 제41조·제42조)
- 증빙 없음 → 손금불산입·대표자상여
- 적격증명서류 미수취(건당 3만 원 초과, 경조금은 20만 원 초과) → 손금불산입·기타사외유출
- 나머지 = 시부인 대상. 한도 = 기본(중소 3,600만·일반 1,200만 × 월수/12) + 수입금액 한도(일반수입 구간 적용, 특수관계 수입은 총수입 구간 적용분 중 특수관계 몫 × 10%) (+문화 한도는 culture 지출 있을 때)
- 한도초과 → 손금불산입·기타사외유출
- 기존 entertainment_limit 계산 로직 재사용 가능

## 3. financial_income_aggregate — 종합소득 합산 금융소득(이자·배당)과 Gross-up
입력: year, items: [{kind, amount, ...}]
kind(최소): '예금이자' | '비영업대금이익' | '외상매출금지급기일연장이자'(→ 사업소득, 제외) | '소비대차전환이자'(→ 비영업대금이익) | '투자신탁환매이익'(components: [{asset: '상장주식'|'비상장주식'|'채권'|..., gain}] — 상장주식 양도·평가 손익 제외, 나머지 손익 통산) | '파생결합사채이익'(배당) | '장내파생상품'(양도소득, 제외) | '상장법인현금배당' | '비상장법인현금배당' | '의제배당_잉여금자본전입'(source: '주식발행초과금'|'자기주식처분이익'|'이익잉여금'|..., self_stock_shift?: 금액 — 자기주식 미배정 지분율 상승분) | '인정배당'(소득처분) | '저축성보험차익'(premium, payout, contract_year, annuity?: bool)
규칙(소득세법 제14조·제16조·제17조·제56조, 시행령 해당 조)
- 항목별 이자/배당/제외 판정과 Gross-up 대상 여부(법인세 과세 잉여금 재원 배당만)
- 금융소득 합계 ≤ 2천만 원 → 분리과세(합산 0)
- 초과 시 2천만 원 구간 채우는 순서: 이자 → Gross-up 비대상 배당 → Gross-up 대상 배당. Gross-up 금액 = 2천만 원 초과 구간에 들어간 대상 배당 × 가산율(2024년 이후 10%, 2023년 11%)
- 결과: 이자소득금액, 배당소득금액(Gross-up 포함), 합산액
