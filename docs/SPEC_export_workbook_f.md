# SPEC_export_workbook_f — 나머지 6개 도구 살아 있는 수식 · 작성 Claude 2026-10-25
브랜치 `feat/export-workbook`(이어서, PR #31). 정답 테스트 `tests/test_export_workbook_f.py` + 기존 전부 통과. 커밋 1~2개(제목 예: feat: 감가상각·수입배당·부가세·총급여·금융소득 계산식). push 금지, 테스트 수정 금지.

## 왜
SPEC_export_workbook_c로 기업업무추진비·차가감소득금액은 엑셀에서 셀을 누르면 식이 보이고 입력을 바꾸면 따라 바뀐다. 나머지 도구는 아직 값만 있다. 같은 틀(`계산식_입력`·`계산식`)을 6개 도구에 붙인다. export_workbook 쪽은 이미 `계산식`이 있으면 수식 시트를 만드므로 고칠 것 없음(필요하면 버그만).

## 규칙 (SPEC_export_workbook_c 1절 그대로)
- `계산식_입력`: `[{이름, 값, 설명}]`, `계산식`: `[{이름, 식, 값, 설명?}]`. 식은 엑셀 문법(`=` 없이) — 이름·숫자·`+ - * /`·괄호·`MIN`·`MAX`·`IF`·`ROUNDDOWN`·`> < >= <=`만. 이름은 한글·영문·숫자·`_`, 첫 글자 한글/영문.
- 모든 단계 식은 이름을 하나 이상 참조. 각 단계 `값` = 도구가 실제 계산한 값 = 식을 입력값으로 계산한 값(1원 미만 차이만 허용). 절사는 `ROUNDDOWN(x, 0)`.
- 판단을 거친 값(적용 상각률, 익금불산입률, 비과세 판정 후 금액, Gross-up 대상 여부 등)은 그 판단 결과를 입력으로 두고 `설명`에 판단 요지와 조문.
- 기존 결과 키·값·근거는 바꾸지 않는다.
