# SPEC_gold_gaps2 — 도구 공백 5건: 새 도구 5개 · 작성 Claude 2026-10-24

브랜치 `fix/gold-gaps2`(main에서). 대상 `korean_tax_calc_mcp/server.py`(도구 등록) + 계산은 `engine/` 아래 알맞은 파일(`calc_cit.py`·`calc_vat.py`, 소득세는 기존 소득세 엔진 파일). 정답 테스트 `tests/test_gold_gaps2.py` 전부 통과, 기존 테스트 전부 통과. 커밋 1개(제목은 실행 지시대로). push 금지.

## 왜
정답 인자 세트(계산 71문항)에서 도구가 아예 없는 문항 22개 중 계산 규칙이 분명한 5가지를 도구로 만든다. 판단(무엇이 주택인지, 어떤 지출이 주요경비인지)은 입력의 `구분`으로 받고, 법령 규칙(제외·한도·체감률·상계 한도)은 도구가 적용한다.

## 공통
- 다른 도구와 같은 응답 모양: `_ok({...}, 근거)` 형식으로 `결과`·`계산`·`판단`(리스트, 각 원소 `{"항목","결론","근거"}`)·`근거`. 세무조정이 생기면 `결과["세무조정"] = [{"구분","금액","소득처분"}]`.
- 비율 입력은 0~1 소수 또는 % 둘 다 받는다(1 초과면 ÷100). 금액은 원 단위 정수, 결과도 정수(원 미만 버림).
- 필수 입력이 빠지거나 `구분` 값이 허용값 밖이면 기존 도구처럼 `"입력 확인 필요 — …"` error.
- 도구 설명 첫 줄은 "무엇(언제)" 한 문장, 이어서 입력→인자 대응, 결과, 근거. 기존 도구 설명 스타일을 따른다.

## 1. corporate_deemed_rent_income — 법인 임대보증금 간주익금(조특법 제138조, 조특령 제132조)
입력
- `year`(int), `rentals`: `[{구분: '주택'|'비주택', 보증금, 건설비(건물 취득·건설 누계, 토지 제외), 임대면적비율(선택, 기본 1 = 건물 전체 임대), 일수(선택, 기본 그 해 일수)}]`
- `financial_income`(int, 기본 0): 비주택 임대사업에서 생긴 수입이자·할인료·배당금 등 금융수익 합계
- `rate`(선택): 정기예금이자율. 없으면 `calc_vat.DEEMED_RENT_RATE`의 그 연도 값
- `debt_over_2x`(bool, 기본 True): 차입금적수 > 자기자본적수 × 2, `rental_main_business`(bool, 기본 True): 부동산임대업 주업
규칙
- 둘 중 하나라도 False면 간주익금 0, 판단 `"적용 대상 아님 — 차입금 과다·부동산임대 주업 법인만 (조특법 제138조①)"`.
- 주택(부수토지 포함) 임대보증금은 제외(조특법 제138조① 괄호). 판단에 제외 사실을 적는다.
- 비주택만: 보증금적수 = Σ 보증금×일수, 건설비상당액적수 = Σ 건설비×임대면적비율×일수.
- 간주익금 = max(0, (보증금적수 − 건설비상당액적수) ÷ 연일수(윤년 366) × rate − financial_income). 원 미만 버림.
- 세무조정 `{"구분": "임대보증금 간주익금", "금액": x, "소득처분": "기타사외유출"}`(x > 0일 때).
결과 키: `결과.간주익금`, `계산.보증금적수`, `계산.건설비상당액적수`, `계산.제외_주택보증금`.

## 2. estimated_business_income — 추계 사업소득금액(소득령 제143조, 제208조⑤)
입력
- `year`, `industry_group`: `'가'|'나'|'다'`(가: 농업·도소매·부동산매매 등, 나: 제조·숙박음식·건설 등, 다: 부동산임대·서비스 등)
- `prior_year_revenue`(직전연도 수입금액), `revenues`: `[{구분: '매출'|'보조금'|'유형자산처분'|'기타', 금액}]`
- `expenses`: `[{구분: '매입'|'임차료'|'인건비'|'기타'|'자산취득', 금액}]` — 증빙으로 입증된 지출
- `base_rate`(기준경비율), `simple_rate`(단순경비율), `new_business`(bool, 기본 False), `multiplier`(선택, {간편: 2.8, 복식: 3.4} 기본)
규칙
- 기준금액표(직전연도 수입금액): 간편장부대상자 가 3억·나 1.5억·다 7,500만 미만, 단순경비율 대상자 가 6,000만·나 3,600만·다 2,400만 미만.
- 장부구분: 직전연도 수입금액이 간편장부 기준 미만(또는 신규)이면 `간편장부대상자`, 아니면 `복식부기의무자`.
- 수입금액 = 매출 + 보조금 + 기타 + (복식부기의무자면 유형자산처분, 간편장부대상자면 제외 — 판단에 적음).
- 적용방법: 직전 수입금액이 단순경비율 기준 미만(또는 신규)이고 **당해 수입금액이 간편장부 기준 미만**이면 `단순경비율`, 아니면 `기준경비율`(소득령 제143조④).
- 단순경비율: 소득 = 수입금액 × (1 − simple_rate).
- 기준경비율: 주요경비 = 매입 + 임차료 + 인건비(기타·자산취득은 제외, 판단에 제외 항목 적음). 복식부기의무자는 기준경비율 × 1/2. 소득 = 수입금액 − 주요경비 − 수입금액 × 적용 기준경비율. 단, 단순경비율 소득 × 배율(간편 2.8, 복식 3.4)을 넘으면 그 금액(소득령 제143조③ 단서). 최소 0.
결과 키: `결과.사업소득금액`, `계산.수입금액`, `계산.장부구분`, `계산.적용방법`, `계산.주요경비`, `계산.기준경비율_소득`, `계산.한도`(기준경비율일 때).

## 3. vat_exempt_use_deemed_supply — 면세전용 간주공급 과세표준(부가법 제10조①, 부가령 제66조)
입력
- `use_date`('YYYY-MM-DD', 면세사업에 쓰기 시작한 날), `mode`: `'전부'|'일부'`(일부 = 과세·면세 공통 사용)
- `assets`: `[{구분: '건물'|'구축물'|'기타'|'토지'|'비상각', 취득일, 취득가액, 매입세액공제(bool, 기본 True), 시가(선택)}]`
- `supplies`(일부일 때 필수): `{taxable, exempt}` — 전용한 날이 속하는 과세기간의 공급가액
규칙
- 토지는 제외(면세 재화). 매입세액공제를 받지 않은 자산은 제외(부가법 제10조① 괄호). 판단에 제외 사유.
- 감가상각자산 간주시가 = 취득가액 × (1 − 체감률 × 경과과세기간수), 체감률 건물·구축물 5%, 기타 25%, 0 미만이면 0.
- 경과과세기간수 = (전용일이 속하는 과세기간 순번) − (취득일이 속하는 과세기간 순번). 과세기간은 1기(1~6월)·2기(7~12월), 기간 개시일 후 취득·전용은 그 개시일로 본다(영 제66조②). 예: 2022.10.5 취득, 2024.10.1 전용 → 4.
- 비상각 재화는 `시가` 필수, 그대로 사용.
- 일부: 면세비율 = exempt ÷ (taxable + exempt). 5% 미만이면 과세표준 0(영 제66조③ 단서), 아니면 간주시가 합 × 면세비율. 전부: 간주시가 합.
결과 키: `결과.과세표준`, `계산.자산별`: `[{구분, 경과과세기간수, 간주시가}]`(제외 자산은 `제외사유`), `계산.면세비율`(일부일 때).

## 4. liquidation_income — 청산소득금액(법인세법 제79조)
입력
- `assets_realized`(환가 총액 int, 또는 `[{항목, 금액}]`), `liabilities_paid`(부채 상환액)
- `capital`(자본금), `surplus`(자본잉여금+이익잉여금), `yubo`(세무상 유보 잔액, 기본 0, △유보는 음수)
- `carryforward_loss`(세무상 이월결손금 잔액, 기본 0), `capitalized_surplus_2y`(해산등기일 전 2년 이내 자본금에 전입한 잉여금, 기본 0), `refund_tax`(해산등기일 현재 환급될 법인세, 기본 0)
규칙
- 잔여재산가액 = 환가 총액 − 부채 상환액.
- 2년 이내 자본전입 잉여금은 전입하지 않은 것으로 본다: 자본금 −= x, 잉여금 += x(법 제79조⑤).
- 잉여금 = surplus + yubo. 이월결손금 상계 = min(carryforward_loss, 잉여금) — 잉여금 초과분은 없는 것으로 본다(법 제79조④).
- 자기자본총액 = 자본금 + 잉여금 − 상계액 + refund_tax.
- 청산소득금액 = 잔여재산가액 − 자기자본총액(음수면 그대로 두고 판단에 `"청산소득 없음"`).
결과 키: `결과.청산소득금액`, `계산.잔여재산가액`, `계산.자기자본총액`, `계산.결손금_상계`, `계산.자본금`, `계산.잉여금`.

## 5. income_adjustment_total — 차가감소득금액 집계(법인세 과세표준 및 세액조정계산서)
입력
- `net_income`(당기순이익), `items`: `[{항목(이름), 종류(아래 사전), 금액, 방향(선택 '가산'|'차감'|'없음'), 소득처분(선택)}]`
- `donation_excess`(기부금 한도초과액, 기본 0), `donation_carryover_deduction`(기부금 한도초과 이월액 손금산입, 기본 0)
종류 사전(방향, 기본 소득처분, 근거) — `vocab.py`나 엔진 상수로 둔다
| 종류 | 방향 | 소득처분 | 근거 |
|---|---|---|---|
| 법인세비용 | 가산 | 기타사외유출 | 법 제21조1호 |
| 법인지방소득세 | 가산 | 기타사외유출 | 법 제21조1호 |
| 벌금·과태료·가산세 | 가산 | 기타사외유출 | 법 제21조3호 |
| 환급금이자 | 차감 | 기타 | 법 제18조4호 |
| 자기주식처분이익(자본잉여금) | 가산 | 기타 | 법 제15조①·영 제11조2호의2 |
| 미수이자(원천징수대상) | 차감 | △유보 | 영 제70조①1호 |
| 비지정기부금 | 가산 | 기타사외유출 | 법 제24조 |
| 기업업무추진비 한도초과 | 가산 | 기타사외유출 | 법 제25조 |
| 감가상각비 한도초과 | 가산 | 유보 | 법 제23조 |
| 업무무관 지급이자 | 가산 | 기타사외유출 | 법 제28조 |
| 수입배당금 익금불산입 | 차감 | 기타 | 법 제18조의2 |
| 이월결손금 보전 자산수증이익 | 차감 | 기타 | 법 제18조6호 |
| 사업용 재산세 | 없음 | — | 법 제19조(손금) |
| 기부금 한도초과 | (차가감 이후) | 기타사외유출 | 법 제24조 |
규칙
- `방향`을 주면 그것을 쓰고, 없으면 사전. 사전에 없는 종류인데 방향도 없으면 error `"입력 확인 필요 — 항목 '…': 종류 사전에 없음, 방향을 주세요"`.
- 종류 '기부금 한도초과'는 차가감에 넣지 않고 `donation_excess`에 더한다(판단 `"차가감소득금액 이후 가산"`).
- 방향 '없음'은 세무조정에 넣지 않고 판단에만 `"조정 없음"`.
- 차가감소득금액 = net_income + Σ가산 − Σ차감. 각사업연도소득금액 = 차가감소득금액 + donation_excess − donation_carryover_deduction.
결과 키: `결과.차가감소득금액`, `결과.각사업연도소득금액`, `결과.익금산입_손금불산입`, `결과.손금산입_익금불산입`, `결과.세무조정`(원소 `구분`은 입력 `항목` 이름 그대로).
