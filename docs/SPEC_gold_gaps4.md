# SPEC_gold_gaps4 — 부가세 판정 도구 2개: 매입세액 공제 판정, 간주공급 판정 · 작성 Claude 2026-10-24

브랜치 `feat/gold-gaps4`(main에서). 정답 테스트 `tests/test_gold_gaps4.py` 9개 + 기존 전부 통과. 커밋 1개(제목은 실행 지시대로). push 금지, 테스트 수정 금지.

## 왜
정답 인자 세트에서 매입세액 공제 판정이 3문항(도구 없음 1·부분 2), 간주공급 판정이 1문항. 둘 다 "항목마다 공제/과세 여부를 조문으로 판정 → 합계"라 원장형 입력에 맞다. 판정은 도구가 하고, 모델은 항목의 성격·증빙·날짜만 옮긴다.

## 공통
- 응답 모양은 다른 원장형 도구와 같음: `_ok({...}, 근거)`에 `결과`·`계산.항목별`·`판단`(각 `{항목, 결론, 근거}`)·`산식`.
- 금액은 원 정수, 세액은 원 미만 버림. 공급대가만 주면 세액 = 공급대가 × 10/110, 공급가액을 주면 × 10%.
- 허용값 밖 값·필수값 누락은 `"입력 확인 필요 — …"` error(계산하지 않음). `period`는 'YYYY-1'|'YYYY-2'.
- 엔진 함수는 `engine/calc_vat.py`, 도구 등록은 `server.py`. 경과과세기간은 기존 `calc_vat.elapsed_periods` 사용.

## 1. vat_input_tax_deduction — 매입세액 공제 판정(부가법 제38조·제39조·제46조, 영 제75조)
입력: `period`, `filing`('예정'|'확정'), `items: [{항목, 증빙, 공급가액? | 공급대가?, 성격, 공급자?, 공급시기?, 발급일?, 실제공급가액?}]`
- `증빙`: '세금계산서'|'신용카드'|'현금영수증'|'영수증'. `성격`: '일반'|'접대'|'비영업용승용차'|'토지관련'|'면세사업'|'사업무관'. `공급자`: '일반과세자'(기본)|'간이과세자_세금계산서'|'간이과세자_영수증'.
- 공급가액·공급대가 둘 다 없으면 error.
판정 순서(항목마다, 처음 걸리는 사유로 불공제):
1. 성격 '접대' → 불공제(법 제39조①6호), '비영업용승용차'(구입·임차·유지, 유류 포함) → 불공제(①5호), '토지관련'(토지 조성·형질변경, 철거 목적 건물 취득·철거비 포함) → 불공제(①7호, 영 제80조), '면세사업' → 불공제(①7호), '사업무관' → 불공제(①4호).
2. 증빙 '영수증' → 불공제(법 제39조①2호 취지: 적격증빙 아님).
3. 증빙 '신용카드'·'현금영수증'인데 공급자 '간이과세자_영수증'(신규 간이·영수증 발급 대상) → 불공제(법 제46조③ 단서·영 제88조⑤). 일반과세자·간이과세자_세금계산서면 공제.
4. 증빙 '세금계산서'이고 `공급시기`·`발급일`이 있으면: 발급일이 그 공급시기가 속한 과세기간의 확정신고기한(1기 7/25, 2기 다음해 1/25) 이내 → 공제(영 제75조3호). 기한 후 1년 이내 → 공제 + 판단에 `"지연수취 — 가산세 대상(법 제60조⑦)"`(영 제75조7호). 그보다 늦으면 불공제(법 제39조①2호).
5. `실제공급가액`이 있으면(필요적 기재사항 착오) 공제세액은 실제공급가액 × 10%, 판단 `"착오 기재 — 그 밖의 증빙으로 실제 거래 확인 시 실제분 공제 (영 제75조2호)"`.
결과: `결과.공제매입세액`, `결과.불공제매입세액`, `계산.항목별: [{항목, 세액, 공제세액, 불공제사유?}]`.

## 2. vat_deemed_supply_items — 간주공급·판매 과세표준 판정(부가법 제10조, 영 제19조의2·제20조, 제66조)
입력: `period`, `items: [{항목, 거래, 매입세액공제(bool), 금액? | 시가? | 감가상각?, 1인당_연간금액?, 견본_광고선전물?}]`
- `거래`: '판매'|'면세전용'|'비영업용승용차전용'|'타사업장반출'|'개인적공급'|'사업상증여'|'폐업시잔존'.
- `감가상각`: `{구분:'건물'|'구축물'|'기타', 취득가액, 취득일, 공급일}` → 간주시가 = 취득가액 × (1 − 체감률 × 경과과세기간수), 체감률 건물·구축물 5%·기타 25%, 0 미만 0(영 제66조). 감가상각을 주면 시가 대신 이 값.
규칙:
- '판매': `금액` 그대로 과세(매입세액공제 여부와 무관 — 불공제 재화의 판매도 과세).
- '타사업장반출': 판매 목적 반출, `금액`(반출가액 = 취득가액 등) 과세(법 제10조③). 매입세액공제와 무관.
- 나머지 간주공급('면세전용'·'비영업용승용차전용'·'개인적공급'·'사업상증여'·'폐업시잔존'): `매입세액공제`가 False면 0, 제외사유 `"매입세액 공제받지 않은 재화 — 간주공급 아님 (법 제10조 괄호)"`. True면 시가(또는 감가상각 간주시가) 과세.
- '개인적공급': 경조사·명절·창립기념일 등 1인당 연간 10만원 이하분은 공급 아님, 초과하면 초과액만 과세(영 제19조의2, 2022.2.15 이후). `1인당_연간금액`이 있으면 과세 = max(0, 1인당_연간금액 − 100,000) × (시가 ÷ 1인당_연간금액)… 단, 한 사람 한 줄로 받으므로 간단히 `max(0, 시가 − 100,000)`.
- '사업상증여': `견본_광고선전물`이 True면 0(법 제10조⑤ 단서).
결과: `결과.과세표준`, `계산.항목별: [{항목, 거래, 과세표준, 제외사유?}]`.
